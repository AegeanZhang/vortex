# 工程规范

本目录规定如何编写、验证、Review 和提交 Vortex 的代码与文档。架构边界和技术选择见 [`../architecture/README.md`](../architecture/README.md)。

- [`coding-style.md`](coding-style.md)：Rust 格式、命名和代码组织约定。
- [`testing.md`](testing.md)：测试分层、特殊场景与提交前检查。
- [`git-workflow.md`](git-workflow.md)：Commit 和 Pull Request 约定。
- [`review-checklist.md`](review-checklist.md)：架构、正确性、安全与兼容性检查清单。

根目录 [`AGENTS.md`](../../AGENTS.md) 定义修改权限。工程规范说明“怎样做”，不能扩大其中规定的可修改范围。
